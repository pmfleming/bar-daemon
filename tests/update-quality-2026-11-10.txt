Changes and preserved boundaries
- Remove the unused durable_updates predicate and private service forwarding
  wrapper; dispatch native durable update delivery directly at its D-Bus owner.
  daemon.rs exports InternalNotifications only for Component::Notifications;
  notification_services constructs Native or SwayNc. basic_services and
  activity_services construct Remote but never export this endpoint. The removed
  Remote forwarding branch therefore had no production caller. Generic desktop
  forwarding remains; the SwayNc fallback still clears actions before sending.
  Native delivery still awaits engine persistence before acknowledging. Incoming
  size/JSON admission, fdo error mapping and engine run/key bounds are preserved.
- Reuse the update adapter's state/history publication closure for watch events
  and disconnection. Remove its unused notification-service Arc parameter.
  Reconnection delay, disconnect errors and history invalidation are unchanged.
- Combine two overlapping persistence fixtures into one private UnixStream D-Bus
  journey: retries, DND, clear/dismissal, durable history and engine restart. Add
  malformed JSON, oversized payload, invalid run ID and oversized key rejection.
  Drop both isolated peers before restart; no session-bus environment mutation.
  The existing route-retirement matrix retains replacement/eviction/delete/
  dismiss/clear coverage, so duplicate route checks leave this combined journey.
  Keep the internal_notification constructor exercised by the combined test.
- Apply rustfmt to the existing update_history line that failed baseline fmt.
