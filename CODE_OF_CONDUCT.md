# Code of Conduct

We are committed to a welcoming, harassment-free project for everyone.

Participants should be respectful, assume good intent, give actionable technical feedback, and accept responsibility for mistakes. Harassment, discriminatory language, personal attacks, intimidation, and publication of private information are unacceptable.

Project maintainers may edit or remove contributions and restrict participation when conduct is inappropriate, threatening, or harmful. Enforcement decisions should be proportionate, documented privately, and protect reporter confidentiality.

Report conduct concerns privately to the repository owner through the repository hosting service. Good-faith reports will be reviewed promptly without retaliation.
